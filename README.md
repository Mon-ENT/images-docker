# Mon-ENT/images-docker

Ce repository sert à stocker les fichiers nécessaires au build des images Docker.

La liste de tous les modules distribués sous la forme d'une image optimisée est disponible [ici](https://github.com/orgs/Mon-ENT/packages).

## Comment a été construit le `Dockerfile.base` ?

Ce fichier est basé sur un fichier généré par le CLI d'Edifice, modifié afin de s'adapter à n'importe quel module.

À noter que cet outil a ses sources privées sur GitHub, mais reste accessible dans sa version compilée sur le Maven d'Edifice.
